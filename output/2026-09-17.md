## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的Agent需要从网页抓取结构化数据用于RAG或工具调用时，直接用requests库可能被反爬或解析失败。推荐使用firecrawl的API，一行代码完成搜索+抓取+交互：

```python
from firecrawl import FirecrawlApp
app = FirecrawlApp(api_key="YOUR_KEY")
# 抓取并自动转为Markdown
result = app.scrape_url("https://example.com", params={"formats": ["markdown"]})
print(result["markdown"])
```

注意：API密钥需从firecrawl.dev获取，不要硬编码在公开仓库中，建议用环境变量。该服务有免费额度，适合原型验证。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
