## 今日 Agent 开发技巧

### firecrawl/firecrawl

**场景：** 当你的Agent需要从网页获取实时信息（如股价、新闻），但传统爬虫常因页面结构变化而失效。

**做法：** 用 Firecrawl 的 `scrape_url` 接口替代手动解析 HTML，它会自动提取结构化数据（标题、正文、元数据）。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="YOUR_KEY")
result = app.scrape_url("https://example.com")
print(result["data"]["content"])  # 直接获取清洗后的文本
```

**安全提示：** 无需执行模型生成的代码，Firecrawl 返回纯 JSON，无注入风险。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
