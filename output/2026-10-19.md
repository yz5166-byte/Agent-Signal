## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的 Agent 需要从网页抓取结构化数据（如产品列表、新闻摘要），但网站开始封禁 AI 爬虫时（条目[14]），可以用 `firecrawl` 的 API 替代裸请求。它自动处理反爬、返回 Markdown/JSON，避免被屏蔽。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
# 抓取并结构化输出
result = app.scrape_url("https://example.com", params={"formats": ["markdown", "structured"]})
print(result["data"]["content"])  # 安全，不执行模型代码
```

注意：`firecrawl` 是第三方服务，需注册获取 API Key，不涉及裸执行代码。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
