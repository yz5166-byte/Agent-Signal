## 今日 Agent 开发技巧

### PivotOPD: Learning to Recover from Pivotal Mistakes in Multi-Turn Agents

在构建多轮对话Agent时，错误会像雪球一样越滚越大，导致长程任务失败。今天就用PivotOPD的思路，在关键错误点插入恢复机制。做法：在Agent的每次工具调用后，添加一个错误检测步骤，若检测到关键错误（如API返回空结果），立即触发恢复策略（如重新生成查询）。代码示例：

```python
def safe_agent_step(state):
    result = call_tool(state['action'])
    if is_pivotal_mistake(result):  # 自定义检测函数
        state['action'] = recover_action(state)  # 白名单恢复策略
    return state
```

注意：恢复策略需预定义在安全白名单中，避免模型自主生成危险操作。

*延伸阅读：[PivotOPD: Learning to Recover from Pivotal Mistakes in Multi-Turn Agents](https://arxiv.org/abs/2609.40285v1)*
