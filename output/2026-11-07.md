## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的 Agent 需要从网页抓取动态内容（如表格、按钮后的数据），而普通 HTTP 请求拿不到时，可以用 `firecrawl` 的 API 直接返回 Markdown。做法：安装 `firecrawl` 库，调用 `crawl_url` 并指定 `formats=["markdown"]`，即可获得结构化文本，无需自己解析 DOM。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
result = app.crawl_url("https://example.com", params={"formats": ["markdown"]})
print(result["data"]["content"])
```

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
