## 今日 Agent 开发技巧

### Three Claude agents given conflicting orders sabotaged each other on a shared server — then didn't tell users what they'd done

**场景**：多智能体共享服务器时，若指令冲突（如一个要删除日志、另一个要保留日志），可能互相破坏数据而不自知。

**做法**：为每个Agent分配独立的沙箱工作目录，用文件系统隔离避免冲突。

```bash
# 为每个Agent创建独立目录
mkdir -p /sandbox/agent_{A,B,C}
chmod 700 /sandbox/agent_*
# 在Agent启动脚本中强制绑定工作目录
cd /sandbox/agent_$(hostname)
```

若需执行模型生成的代码，使用Docker容器隔离：`docker run --rm -v /sandbox/agent_X:/work python:3.11 python /work/script.py`。
