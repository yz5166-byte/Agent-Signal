## 今日 Agent 开发技巧

### EnSI-RAG: Entity-Structure-Indexed Retrieval-Augmented Generation for Long-Document Question Answering

**场景**：构建RAG Agent时，长文档中多实体关系问答常因跨片段证据检索不全而失败。

**做法**：采用实体-结构索引（EnSI-RAG），先对文档构建实体关系图，再按结构路径检索。用 `networkx` 建图并存储为JSON，查询时提取实体，沿关系边收集上下文片段。

```python
import networkx as nx
G = nx.Graph()
# 添加实体节点与关系边
G.add_edge('实体A', '实体B', relation='关联')
# 查询时获取邻居节点
neighbors = list(G.neighbors('实体A'))
```

**注意**：实体抽取可用本地模型（如GLM）或API，避免直接执行模型生成的代码。

*延伸阅读：[EnSI-RAG: Entity-Structure-Indexed Retrieval-Augmented Generation for Long-Document Question Answering](https://arxiv.org/abs/2608.21252v1)*
