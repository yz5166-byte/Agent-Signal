## 今日 Agent 开发技巧

### 防御第三方技能劫持：输入输出校验白名单

今天从条目[1]切入：当你的Agent依赖第三方技能（如插件、API）时，攻击者可能通过隐蔽劫持篡改行为，而开发者往往难以察觉。

**做法**：对每个第三方技能调用添加**输入输出校验白名单**。例如，用Pydantic定义技能返回的JSON schema，拒绝不符合结构的响应：
```python
from pydantic import BaseModel, ValidationError

class SkillOutput(BaseModel):
    result: str
    confidence: float = 0.0

# 在调用技能后校验
raw = call_third_party_skill()
try:
    validated = SkillOutput.model_validate(raw)
except ValidationError:
    raise SecurityError("技能输出异常，疑似劫持")
```
这能拦截大部分非预期数据注入，且无需执行模型生成的代码。

*延伸阅读：[Convergent Detour Hijacking: Task-Preserving Resource Amplification in Skill-Based LLM Agents](https://arxiv.org/abs/2608.12273v1)*
