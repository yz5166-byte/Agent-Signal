## 今日 Agent 开发技巧

### firecrawl/firecrawl

**场景：** 当你的 Agent 需要从网页抓取实时信息（如新闻、价格、文档），但目标网站有反爬或动态加载内容时，直接请求 HTML 往往拿不到数据。

**做法：** 集成 [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl) 作为抓取工具。它专为 AI 代理设计，能自动处理 JavaScript 渲染、绕过简单反爬，返回干净 Markdown。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
content = app.scrape_url("https://example.com", params={"formats": ["markdown"]})
print(content["markdown"])
```

直接替换 URL 和 API Key 即可运行，无需处理复杂解析逻辑。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
