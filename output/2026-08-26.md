## 今日 Agent 开发技巧

### 自动维护 Agent 项目文档

**场景：** 你的 Agent 项目代码迭代快，文档总是滞后，需要手动维护 API 与架构说明。

**做法：** 用 `openwiki` 一键生成并自动更新文档。安装后：

```bash
pip install openwiki
cd your-agent-project
openwiki init        # 扫描项目结构
openwiki generate   # 生成 Markdown 文档
```

在 CI/CD 中加入 `openwiki generate` 即可保持文档同步。该工具仅读取本地文件，不执行外部代码，安全可靠。

*延伸阅读：[langchain-ai/openwiki](https://github.com/langchain-ai/openwiki)*
