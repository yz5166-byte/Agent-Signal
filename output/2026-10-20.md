## 今日 Agent 开发技巧

### Same Simulation, Different Evidence: Where Retrieved Tool Output Costs LLM Agents Accuracy

**场景**：Agent 调用工具返回超长 JSON 或日志，被 LLM 上下文窗口截断，导致明明检索到正确答案却答错。

**做法**：在工具输出前用 `json.dumps(data, ensure_ascii=False)[:2000]` 截断，并追加 `... (truncated)` 标记。若需执行模型生成的代码，用 `subprocess.run` 配合 `timeout` 参数在沙箱中运行：

```python
import subprocess
result = subprocess.run(['python3', '-c', code], capture_output=True, text=True, timeout=10)
```

避免裸 `exec`/`eval`。

*延伸阅读：[Same Simulation, Different Evidence: Where Retrieved Tool Output Costs LLM Agents Accuracy](https://arxiv.org/abs/2610.26836v1)*
