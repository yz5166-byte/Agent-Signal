## 今日 Agent 开发技巧

### 安全执行 Agent 生成的代码

**场景：** 当 Agent 需要执行 LLM 生成的代码（如数据分析、自动化脚本）时，直接 `exec/eval` 会带来严重安全风险。

**做法：** 使用 `subprocess` 在隔离的子进程中运行代码，并限制资源与文件系统访问。

```python
import subprocess
import tempfile
import os

# 将生成的代码写入临时文件
with tempfile.NamedTemporaryFile(mode='w', suffix='.py', delete=False) as f:
    f.write(user_generated_code)
    tmp_path = f.name

try:
    # 在子进程中运行，设置超时和沙箱参数
    result = subprocess.run(
        ['python3', '-I', tmp_path],  # -I 隔离模式
        capture_output=True,
        timeout=10,
        env={}  # 清空环境变量
    )
    print(result.stdout.decode())
finally:
    os.unlink(tmp_path)  # 清理临时文件
```

**注意：** 生产环境建议用 Docker 或 gVisor 等容器沙箱进一步隔离。
