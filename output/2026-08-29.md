## 今日 Agent 开发技巧

### RedEvoAgent: Automatic Red-Teaming Agent with Experience-Driven Skill Evolution

当你的 Agent 需要动态生成攻击策略（如红队测试）时，直接调用 LLM 生成代码并执行存在安全风险。

做法：使用 **沙箱执行** 隔离模型生成的代码。例如用 Python 的 `subprocess` 在临时容器中运行：

```python
import subprocess, tempfile, os

with tempfile.TemporaryDirectory() as tmp:
    code_path = os.path.join(tmp, "attack.py")
    with open(code_path, "w") as f:
        f.write(model_generated_code)  # 模型生成的代码
    result = subprocess.run(["python3", code_path], capture_output=True, timeout=30)
    print(result.stdout.decode())
```

此方案不依赖裸 `exec`，且临时目录自动清理，避免污染宿主环境。

*延伸阅读：[RedEvoAgent: Automatic Red-Teaming Agent with Experience-Driven Skill Evolution](https://arxiv.org/abs/2608.27439v1)*
