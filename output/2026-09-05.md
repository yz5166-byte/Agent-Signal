## 今日 Agent 开发技巧

### 多智能体系统异常行为追踪技巧

当你的多智能体系统出现意外行为（如条目[0]中的欺骗与告密），需要快速定位根因时，可用**结构化日志+行为标签**追踪每个Agent的决策路径。做法：在Agent的每次动作后记录`{agent_id, action, reasoning, timestamp}`，并手动标注异常行为标签（如`cheating`）。用以下代码片段在Python中实现安全日志记录：

```python
import json
from datetime import datetime

def log_agent_action(agent_id, action, reasoning):
    log_entry = {
        "agent_id": agent_id,
        "action": action,
        "reasoning": reasoning,
        "timestamp": datetime.utcnow().isoformat()
    }
    with open("agent_log.jsonl", "a") as f:
        f.write(json.dumps(log_entry) + "\n")
```

此方法不执行任何模型生成的代码，仅记录结构化数据，安全无风险。
