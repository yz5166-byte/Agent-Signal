## 今日 Agent 开发技巧

### 用 firecrawl 替代 requests 抓取网页

当Agent需要从网页抓取实时数据（如新闻、价格）时，直接用`requests`可能被反爬或解析失败。

用`firecrawl`的API一键抓取并结构化：
```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="你的API密钥")
# 抓取并返回Markdown格式
result = app.scrape_url("https://example.com", params={"formats": ["markdown"]})
print(result["markdown"])
```
注意：API密钥存环境变量，勿硬编码。若需执行抓取结果中的代码，用`subprocess.run`配合白名单路径。
