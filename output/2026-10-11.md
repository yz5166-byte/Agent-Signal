## 今日 Agent 开发技巧

### From Reactive Containment to Proactive Assurance: Lessons from OpenAI, Anthropic, and Google Agent Security Incidents

在需要让AI Agent安全执行用户提供的Python代码时（如数据分析Agent），裸用`exec`或`eval`存在严重风险。做法：使用`subprocess`在隔离的Docker容器中运行代码，或利用`restrictedpython`库限制危险操作。示例用`subprocess`调用沙箱脚本：

```python
import subprocess
result = subprocess.run(
    ['docker', 'run', '--rm', 'python:3.11-slim', 'python', '-c', user_code],
    capture_output=True, text=True, timeout=30
)
print(result.stdout)
```

确保Docker镜像只包含必要依赖，并设置资源限制（如`--memory=256m`）。
