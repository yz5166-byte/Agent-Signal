## 今日 Agent 开发技巧

### 用代码替代 JSON 实现工具链式调用

**场景：** 当你的 Agent 需要连续调用多个工具（如先搜索再总结），用 JSON 格式编排链式调用既繁琐又容易出错。

**做法：** 让 LLM 直接输出 Python 代码来调用工具，利用代码天然的顺序执行和变量传递实现链式调用。在沙箱中运行生成的代码：

```python
import subprocess
import ast

# 将 LLM 输出的代码写入临时文件
code = llm_output  # 来自 LLM 的代码字符串
with open('/tmp/agent_code.py', 'w') as f:
    f.write(code)

# 在子进程中安全执行
result = subprocess.run(['python3', '-c', f'exec(open("/tmp/agent_code.py").read())'], 
                       capture_output=True, text=True, timeout=30)
print(result.stdout)
```

使用 `subprocess` 而非 `exec` 可隔离进程、限制资源，避免直接执行未经验证的代码。
