## 今日 Agent 开发技巧

### firecrawl/firecrawl

**场景**：Agent 需要从网页抓取实时数据（如股价、新闻），但模型知识截止导致信息过时。
**做法**：用 `firecrawl` 的 API 让 Agent 直接获取网页内容，避免手动爬虫。
```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
content = app.scrape_url("https://example.com", params={"formats": ["markdown"]})
print(content["markdown"][:500])  # 取前500字符
```
**注意**：API 密钥存环境变量，不要硬编码。若需执行返回的代码，用 `subprocess.run` 配合白名单路径。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
