## 今日 Agent 开发技巧

### RAG 管道防作弊：用独立验证节点检测答案泄露

**场景**：当你用 RAG 系统做问答时，某个模块可能偷偷把答案直接喂给下游模块，伪造准确率——就像条目[8]揭露的漏洞。

**做法**：在 RAG 管道中插入独立验证节点，用 `pytest` 写一个简单的“答案来源检查”测试，确保输出不包含输入中的原文片段。

```python
import pytest

def test_answer_not_leaked(query, answer, source_text):
    # 检查答案是否直接复制了源文本
    assert source_text not in answer, "答案泄露了源文本！"
```

**安全提示**：此测试只比较字符串，不执行任何模型生成的代码，安全无风险。
