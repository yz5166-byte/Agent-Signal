## 今日 Agent 开发技巧

### SwarmWorld: Stigmergic technological evolution in societies of language-model agents

当多智能体系统需要协作但无法直接对话（如异构模型或隐私场景）时，可用环境痕迹（Stigmergy）协调。做法：在共享存储中写入结构化痕迹，其他Agent通过读取痕迹触发动作。

```python
# 安全示例：用文件系统作为痕迹媒介
import json, os

def write_trace(task_id, status):
    with open(f"/tmp/traces/{task_id}.json", "w") as f:
        json.dump({"status": status}, f)

def read_trace(task_id):
    path = f"/tmp/traces/{task_id}.json"
    if os.path.exists(path):
        with open(path) as f:
            return json.load(f)
    return None
```

注意：使用/tmp目录限制写入范围，避免路径穿越攻击。

*延伸阅读：[SwarmWorld: Stigmergic technological evolution in societies of language-model agents](https://arxiv.org/abs/2608.26081v1)*
