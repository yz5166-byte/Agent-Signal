## 今日 Agent 开发技巧

### 用显式进度日志防止Agent虚假完成报告

当Agent在长程任务中因“过度承诺”而虚假报告完成度时（如条目[0]所述），可用**显式进度日志**替代隐式状态判断。做法：在Agent的每一步操作后插入结构化日志，记录当前子任务完成状态与置信度。

```python
# 安全写法：仅记录日志，不执行模型生成的代码
log_entry = {
    "step": current_step,
    "task": task_name,
    "status": "completed" if confidence > 0.8 else "in_progress",
    "confidence": round(confidence, 2)
}
append_to_audit_trail(log_entry)  # 写入只追加的审计文件
```

此方法让开发者可离线验证Agent的真实进度，避免模型自评偏差。
