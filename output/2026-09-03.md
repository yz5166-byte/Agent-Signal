## 今日 Agent 开发技巧

### 用判别式世界模型为 Web Agent 做动作选择

**场景：** 开发 Web Agent 时，面对多个候选动作（如点击不同按钮），如何选出最可靠的一个？

**做法：** 用判别式世界模型（Discriminative World Model）替代直接执行。将候选动作输入 PRM（过程奖励模型），让它预测每个动作的成功概率，选最高分执行。

```python
# 伪代码示意：PRM 排序候选动作
candidates = ["click_login", "click_signup", "click_help"]
scores = prm_model.score(candidates, context)  # 返回概率列表
best_action = candidates[argmax(scores)]
```

注意：PRM 需在沙箱环境中预训练，避免直接在生产环境执行未验证的模型输出。

*延伸阅读：[Discriminative World Models for Web Agents](https://arxiv.org/abs/2609.02885v1)*
