## 今日 Agent 开发技巧

### Failure-Transparent Agents: Benchmarking Post-Failure Reporting in Tool-Using Language Models

**场景：** 你在构建一个需要调用外部工具的 Agent，比如让 LLM 搜索网页或操作数据库。工具调用失败后，Agent 往往只返回“操作失败”，却不告诉你具体原因（是 API 超时、参数错误还是权限不足），导致调试困难。

**做法：** 在工具函数中显式捕获异常，并返回结构化的失败报告，包含错误类型、状态码和原始错误信息。

```python
def search_tool(query: str) -> dict:
    try:
        response = requests.get(f"https://api.example.com/search?q={query}", timeout=5)
        response.raise_for_status()
        return {"status": "success", "data": response.json()}
    except requests.exceptions.RequestException as e:
        return {
            "status": "failure",
            "error_type": type(e).__name__,
            "message": str(e),
            "code": getattr(e.response, 'status_code', None)
        }
```

这样 Agent 就能根据 `error_type` 和 `code` 决定重试、换参数还是向用户报告具体问题。

*延伸阅读：[Failure-Transparent Agents: Benchmarking Post-Failure Reporting in Tool-Using Language Models](https://arxiv.org/abs/2609.35732v1)*
