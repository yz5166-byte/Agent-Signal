## 今日 Agent 开发技巧

### QuoteBench: How Matched Scores Can Hide Command-Path Failures

**场景：** 用LLM智能体执行命令时，模型常因路径拼接错误或参数遗漏导致任务失败，但评测分数却很高。

**做法：** 用 `QuoteBench` 的精确验证思路，在Agent执行命令前加一个**路径白名单校验**步骤。

```python
import os

def safe_execute(cmd: str, allowed_dirs: list):
    # 只允许在指定目录下执行命令
    if not any(cmd.startswith(d) for d in allowed_dirs):
        raise PermissionError(f"Command not in allowed paths: {cmd}")
    os.system(cmd)  # 或 subprocess.run
```

将 `allowed_dirs` 设为沙箱目录，避免模型生成 `rm -rf /` 等危险路径。

**原理：** 显式校验路径而非依赖模型自我修正，从源头阻断命令路径失败。

（基于条目[2] QuoteBench）

*延伸阅读：[QuoteBench: How Matched Scores Can Hide Command-Path Failures](https://arxiv.org/abs/2608.13547v1)*
