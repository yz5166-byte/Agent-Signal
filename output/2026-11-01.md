## 今日 Agent 开发技巧

### Pre-Crime for Agents, at the Last Second: Probing When a Recruited Agent Gives In

当多智能体系统中某个Agent可能被诱导违规时（如社交机器人被恶意指令劫持），可以用线性探针在它行动前最后一刻检测意图。做法：在Agent的隐藏层输出上训练一个二分类线性探针（如逻辑回归），实时监控其决策前的中间表征。代码示例：
```python
from sklearn.linear_model import LogisticRegression
probe = LogisticRegression()
probe.fit(hidden_states, labels)  # labels: 0=正常, 1=违规
if probe.predict_proba(current_hidden)[0][1] > 0.8:
    trigger_alert()  # 触发拦截或降权
```
注意：探针训练数据需在沙箱中生成，避免污染生产环境。

*延伸阅读：[Pre-Crime for Agents, at the Last Second: Probing When a Recruited Agent Gives In](https://arxiv.org/abs/2610.40588v1)*
