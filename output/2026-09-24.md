## 今日 Agent 开发技巧

### trailhq/Graft

**场景**：用Claude Code等编码代理处理大型代码库时，频繁加载上下文导致成本高、速度慢。

**做法**：安装Graft作为上下文缓存层。
```bash
pip install graft
cd your-project && graft init
graft run --agent claude-code
```
Graft自动缓存代码库片段，减少重复加载，使API调用更便宜更快。安装前请确认来源安全。

*延伸阅读：[trailhq/Graft](https://github.com/trailhq/Graft)*
