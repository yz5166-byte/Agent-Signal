## 今日 Agent 开发技巧

### AutoScaffold: AI-Guided Scaffolding for Reinforcement Learning of Language Models

当你的Agent需要执行模型生成的代码（如AutoScaffold中RL训练的动态策略）时，直接使用`exec`/`eval`存在严重安全风险。

做法：用`subprocess`在隔离的Docker容器中运行代码。

```python
import subprocess
# 假设code是模型生成的Python脚本
with open('/tmp/agent_script.py', 'w') as f:
    f.write(code)
result = subprocess.run(
    ['docker', 'run', '--rm', '-v', '/tmp/agent_script.py:/script.py', 'python:3.11-slim', 'python', '/script.py'],
    capture_output=True, text=True, timeout=30
)
print(result.stdout)
```

此方案通过容器隔离执行，避免裸`exec`风险。若无法用Docker，可改用`RestrictedPython`库对代码做AST白名单过滤。

*延伸阅读：[AutoScaffold: AI-Guided Scaffolding for Reinforcement Learning of Language Models](https://arxiv.org/abs/2611.14515v1)*
