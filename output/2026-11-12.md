## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的Agent需要从网页抓取实时数据（如新闻、价格），但目标网站结构频繁变化时，可用firecrawl的智能爬取。做法：调用firecrawl的`/scrape`接口，传入URL和`formats: ['markdown']`，自动提取正文并转为结构化文本。代码示例：
```python
import requests
response = requests.post(
    'https://api.firecrawl.dev/v1/scrape',
    json={'url': 'https://example.com', 'formats': ['markdown']},
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)
print(response.json()['data']['content'])
```
注意：API密钥需从firecrawl控制台获取，勿硬编码在公开仓库中。
