## 今日 Agent 开发技巧

### Co-Evolving Acting and Forecasting for Language Agents

当你的 Agent 在长程任务中因稀疏奖励难以收敛时，可以尝试「同步预测未来」的中间步监督。

做法：在每一步行动后，让模型同时预测未来几步的状态或奖励，用这些预测作为密集监督信号。例如在 ReAct 循环中插入：
```python
# 在每一步 action 后，让模型输出 next_state_pred
pred = model.predict_next_state(current_state, action)
loss = mse_loss(pred, actual_next_state)  # 替代稀疏奖励
```
注意：预测模型需与主模型共享部分参数，避免额外开销。此方法无需执行代码，仅需修改训练损失函数。

*延伸阅读：[Co-Evolving Acting and Forecasting for Language Agents](https://arxiv.org/abs/2610.20597v1)*
