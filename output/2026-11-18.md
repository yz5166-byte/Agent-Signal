## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的 Agent 需要从网页抓取结构化数据（如竞品价格、新闻列表）时，直接用 `requests` + 正则容易因页面改版而失效。

做法：用 `firecrawl` 的 API 一键抓取并转成 Markdown 或 JSON，避免手动解析。

```bash
# 安装 firecrawl Python SDK
pip install firecrawl-py

# 抓取网页并返回结构化内容
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key='your-api-key')
result = app.scrape_url('https://example.com', params={'formats': ['markdown']})
print(result['markdown'])
```

注意：API Key 需从 [firecrawl.dev](https://firecrawl.dev) 获取，免费额度足够日常测试。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
