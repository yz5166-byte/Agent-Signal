## 今日 Agent 开发技巧

### Learning When to Think: Adaptive Reasoning for Test-Time Compute Allocation

当你的Agent需要根据任务复杂度动态调整计算资源时，可以用「自适应推理」技巧。做法：在推理前先让模型对问题做快速难度评分（1-5分），然后根据分数决定是否启用深度推理链。代码示例：
```python
def adaptive_reasoning(query):
    difficulty = fast_scorer(query)  # 轻量模型评分
    if difficulty < 3:
        return direct_answer(query)  # 简单问题直接回答
    else:
        return deep_reasoning(query)  # 复杂问题启动链式推理
```
注意：fast_scorer需用独立沙箱运行，避免污染主模型状态。

*延伸阅读：[Learning When to Think: Adaptive Reasoning for Test-Time Compute Allocation](https://arxiv.org/abs/2608.20256v1)*
