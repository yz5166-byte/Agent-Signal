## 今日 Agent 开发技巧

### 用 firecrawl 的 markdown 模式净化抓取内容

**场景**：当你用 `firecrawl` 为 RAG 抓取网页时，直接返回的 HTML 可能包含广告、导航等噪声，影响 Agent 提取关键信息。

**做法**：使用 `firecrawl` 的 `scrape` 接口并指定 `formats: ['markdown']`，自动过滤无关元素，得到干净的纯文本。

```bash
curl -X POST https://api.firecrawl.dev/v1/scrape \
  -H 'Content-Type: application/json' \
  -d '{"url": "https://example.com/article", "formats": ["markdown"]}'
```

若需执行模型生成的抓取代码，请将 URL 加入白名单列表，避免 SSRF 攻击。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
