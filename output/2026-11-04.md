## 今日 Agent 开发技巧

### You don't need long context

当你的Agent需要处理超长文本（如整本书或长对话），但发现后段token成本比前段高7倍时，可以用**频繁压缩法**替代长上下文。

做法：将文本按固定长度（如4K tokens）分段，每段用LLM压缩为摘要，再拼接处理。

```python
def compress_chunks(text, chunk_size=4000):
    chunks = [text[i:i+chunk_size] for i in range(0, len(text), chunk_size)]
    summaries = []
    for chunk in chunks:
        # 调用LLM压缩（示例用占位函数）
        summary = llm_summarize(chunk)  # 替换为实际API调用
        summaries.append(summary)
    return " ".join(summaries)
```

注意：压缩函数需在沙箱环境（如Docker容器）中运行，避免直接执行模型生成的代码。
