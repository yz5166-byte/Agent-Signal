## 今日 Agent 开发技巧

### lexmount/moli

当你需要让 Agent 在网页中执行点击、翻页等操作，但目标页面依赖 JavaScript 动态渲染时，直接用 HTTP 请求拿不到真实内容。

做法：用 `lexmount/moli` 这个轻量无头浏览器，通过 WebSocket 控制页面。安装后运行：
```bash
pip install moli
moli start --port 9222
```
然后在 Agent 代码中用 `moli.connect('ws://localhost:9222')` 获取页面 DOM，再调用 `page.click('#next-button')` 模拟点击。

注意：不要用 `exec` 执行用户输入的 JS 代码，应通过 `page.evaluate` 传入预定义的函数名白名单。

*延伸阅读：[lexmount/moli](https://github.com/lexmount/moli)*
