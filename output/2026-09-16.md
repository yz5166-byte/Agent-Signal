## 今日 Agent 开发技巧

### 多智能体通信加一层输出审查器

**场景**：多智能体协作时，即使每个 Agent 都诚实且胜任，仍可能因缺乏社会约束而整体失败（条目[0]）。

**做法**：为每个 Agent 添加一个**输出审查器**，在它生成消息后、发送前检查是否包含冲突指令或冗余信息。

```python
# 简单审查器示例
def social_harness(message: str, agent_id: str) -> str:
    if "请忽略" in message or "重复" in message:
        return f"[Agent {agent_id} 消息被拦截：检测到冲突或冗余]"
    return message
```

将审查器作为中间件嵌入 Agent 通信管道，无需修改 Agent 内部逻辑。

*延伸阅读：[Agentic Societies Need a Social Harness](https://arxiv.org/abs/2609.17527v1)*
