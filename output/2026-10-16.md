## 今日 Agent 开发技巧

### firecrawl/firecrawl

**场景**：当你需要让 Agent 从网页抓取结构化数据（如新闻标题、商品价格），但目标网站没有 API 时。

**做法**：用 `firecrawl` 库一行代码完成抓取，无需处理反爬或解析 DOM。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
data = app.scrape_url("https://example.com", params={"formats": ["markdown"]})
print(data["markdown"][:200])  # 直接输出 Markdown 格式内容
```

注意：API Key 需从 [firecrawl.dev](https://firecrawl.dev) 获取，免费额度足够日常调试。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
