## 今日 Agent 开发技巧

### KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards

**场景**：当Agent需要执行安全敏感命令（如Kali Linux工具调用）时，直接运行模型生成的代码存在风险。

**做法**：用`subprocess.run`配合白名单命令列表，拒绝未授权的命令。

```python
import subprocess

ALLOWED = {"nmap", "ping", "whois"}
cmd = model_generated_command.split()[0]  # 假设模型输出 "nmap -sT 127.0.0.1"
if cmd in ALLOWED:
    subprocess.run(model_generated_command, shell=True, check=True)
else:
    print(f"Blocked: {cmd} not in whitelist")
```

此方案确保只执行预定义的安全命令，避免裸`exec`风险。

*延伸阅读：[KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards](https://arxiv.org/abs/2610.02206v1)*
