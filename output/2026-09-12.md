## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的Agent需要从网页获取实时数据（如新闻、价格、文档），但传统爬虫不稳定、易被封时，可用firecrawl的上下文API直接集成。

做法：调用`/scrape`端点，传入URL和`formats`参数，返回结构化Markdown。

```python
import requests

response = requests.post(
    "https://api.firecrawl.dev/v1/scrape",
    json={"url": "https://example.com", "formats": ["markdown"]},
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)
print(response.json()["data"]["markdown"])
```

注意：API Key需从firecrawl.dev获取，勿硬编码在公开仓库中。
