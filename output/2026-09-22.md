## 今日 Agent 开发技巧

### Critical-State RL: Diagnosing Trainable States for Multi-Turn Tool Use

当你在多轮工具调用场景中微调 Agent，发现大量训练数据其实对提升效果帮助不大时，可以试试**关键状态诊断法**。

做法：在训练前先跑一轮推理，记录每个步骤的**状态价值**（即该步骤对最终成功的贡献度），只保留价值高于阈值的步骤用于微调。

```python
# 伪代码示意：过滤低价值步骤
def filter_low_value_steps(trajectory, threshold=0.5):
    valuable_steps = []
    for step in trajectory:
        value = estimate_step_value(step)  # 用轻量模型或规则打分
        if value >= threshold:
            valuable_steps.append(step)
    return valuable_steps
```

注意：`estimate_step_value` 需在沙箱环境中实现（如使用 Docker 隔离），避免直接执行模型生成的代码。
