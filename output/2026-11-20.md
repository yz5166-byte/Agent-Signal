## 今日 Agent 开发技巧

### Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)

当 Agent 需要执行模型生成的代码（如 SQL 查询、Shell 命令）时，直接使用 `exec`/`eval` 存在严重安全风险。

做法：用 `subprocess` 在沙箱中运行，或使用白名单限制可执行命令。

```python
import subprocess

def safe_exec(cmd: str):
    # 仅允许安全命令
    allowed = {'ls', 'pwd', 'echo'}
    if cmd.split()[0] not in allowed:
        raise ValueError('Command not allowed')
    subprocess.run(cmd, shell=True, capture_output=True, timeout=5)
```

参考条目 [1] 中 Agent 删除数据库的教训，务必对模型输出做命令白名单校验。
