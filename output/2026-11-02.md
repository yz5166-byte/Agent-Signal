## 今日 Agent 开发技巧

### firecrawl/firecrawl

**场景**：Agent 需要从网页抓取结构化数据（如新闻、商品列表），但目标网站无 API 或反爬严格。

**做法**：用 `firecrawl` 的 `scrape` 接口直接提取 Markdown 文本，避免手动解析 HTML。

```bash
curl -X POST https://api.firecrawl.dev/v1/scrape \
  -H 'Content-Type: application/json' \
  -d '{"url": "https://example.com", "formats": ["markdown"]}'
```

返回的 `data.markdown` 可直接喂给 LLM 做后续处理。注意：生产环境建议在 Docker 容器内运行，限制网络权限，防止爬取敏感域名。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
