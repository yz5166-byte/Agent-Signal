## 今日 Agent 开发技巧

### 用本地CLI让Agent安全编辑Office文档

**场景**：当你的Agent需要直接操作Office文档（如生成报告、修改表格），但依赖第三方API有延迟或隐私风险时。

**做法**：使用 `genspark-ai/genoffice` 的CLI接口，让Agent通过命令行安全调用本地Office编辑功能。

```bash
# 示例：Agent调用CLI创建并写入文档
genoffice create report.docx --content "# 周报\n- 完成模块A"
genoffice edit report.docx --replace "模块A" "模块B"
```

**注意**：CLI运行在本地沙箱中，Agent仅传递结构化参数，不执行任意代码，避免裸 `exec` 风险。
