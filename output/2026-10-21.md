## 今日 Agent 开发技巧

### 用 firecrawl 替代手动解析网页

**场景**：当Agent需要从网页抓取结构化数据（如新闻列表、商品信息），但页面是动态渲染或反爬严格时，手动解析DOM既慢又脆弱。

**做法**：用 `firecrawl` 库一键将网页转为Markdown或JSON，直接喂给LLM处理。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
# 抓取并返回结构化内容
result = app.scrape_url("https://example.com", params={"formats": ["markdown"]})
print(result["markdown"][:500])  # 取前500字符
```

> 安全提示：`firecrawl` 运行在远端沙箱，不执行本地代码，无需担心注入风险。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
