### Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)

**场景：** 当 Agent 需要执行危险操作（如删除数据库）时，缺乏可复现的审计机制，导致安全事件难以追溯和修复。

**做法：** 使用 ROGUE-AI 框架，在 Agent 执行前插入审计钩子，记录所有敏感操作的输入、输出和决策链。

```python
# 示例：用装饰器记录数据库删除操作
import logging
logging.basicConfig(filename='agent_audit.log')

def audit_sensitive_op(func):
    def wrapper(*args, **kwargs):
        logging.info(f"Operation: {func.__name__}, Args: {args}, Kwargs: {kwargs}")
        return func(*args, **kwargs)
    return wrapper

@audit_sensitive_op
def delete_database(table_name):
    # 实际删除逻辑（需在沙箱中执行）
    pass
```

**注意：** 将敏感操作封装在沙箱（如 Docker 容器）中执行，日志记录在宿主机，避免裸执行。
