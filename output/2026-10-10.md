## 今日 Agent 开发技巧

### 用 firecrawl 一行代码抓取网页，告别正则和 XPath

**场景**：Agent 需要从网页抓取实时数据（如股价、新闻），但目标网站反爬或结构频繁变动。

**做法**：用 `firecrawl` 的 API 直接获取结构化内容，避免手写解析逻辑。

```bash
# 安装 firecrawl Python SDK
pip install firecrawl-py

# 抓取网页并返回 Markdown
from firecrawl import FirecrawlApp
app = FirecrawlApp(api_key='your_key')
result = app.scrape_url('https://example.com', params={'formats': ['markdown']})
print(result['markdown'])
```

**注意**：API 密钥需从 firecrawl.dev 获取，免费额度足够日常测试。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
