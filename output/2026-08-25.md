## 今日 Agent 开发技巧

### The Interaction Tax: When Communication Erases Diversity in Multi-Agent Teams

**场景：** 多智能体协作时，频繁通信反而让所有Agent趋同，失去多样性，导致团队表现下降（条目[0]）。

**做法：** 在通信前加入**多样性检查**——计算各Agent当前输出的语义相似度，若超过阈值则强制引入随机扰动或切换策略。

```python
from sentence_transformers import SentenceTransformer, util
model = SentenceTransformer('all-MiniLM-L6-v2')

def check_diversity(agents_outputs, threshold=0.85):
    embeds = model.encode(agents_outputs)
    sim = util.cos_sim(embeds, embeds)
    return sim.mean().item() < threshold  # 低于阈值才允许通信
```

**安全提示：** 纯数值计算，无代码执行风险。

*延伸阅读：[The Interaction Tax: When Communication Erases Diversity in Multi-Agent Teams](https://arxiv.org/abs/2608.23541v1)*
