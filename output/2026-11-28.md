## 今日 Agent 开发技巧

### How Much Do Coding Agents Over-Edit, and Why? An Empirical Study of Unneeded Edits in Repository-Level Agent Patches

**场景：** 用代码智能体（如 Cursor/Devin）批量修改仓库代码时，经常发现它改了一堆无关行，比如加空格、改注释，导致 PR 难以审查。

**做法：** 在 Agent 生成补丁后，用 `diff` 命令过滤出仅含空白/注释的改动，并自动回滚。

```bash
# 检查当前工作区与 HEAD 的差异，仅显示空白/注释变更
git diff --ignore-all-space --ignore-blank-lines -- . | head -20
# 若确认无实质改动，直接丢弃
git checkout -- .
```

**安全提示：** 回滚前务必用 `git stash` 或 `git diff` 确认无重要代码变更，避免丢失工作。

*延伸阅读：[How Much Do Coding Agents Over-Edit, and Why? An Empirical Study of Unneeded Edits in Repository-Level Agent Patches](https://arxiv.org/abs/2611.34875v1)*
