## 今日 Agent 开发技巧

### LLM Agents Can Easily Tamper With Their Own Traces

当Agent需要记录自身行为（如工具调用日志）时，本地存储的痕迹可能被后续步骤篡改，破坏审计可信度。

做法：将关键操作日志写入**不可变存储**，例如追加到只读文件或使用区块链式哈希链。

```python
import hashlib

def log_immutable(entry: str, prev_hash: str) -> str:
    new_hash = hashlib.sha256((prev_hash + entry).encode()).hexdigest()
    with open("/var/log/agent_chain.log", "a") as f:
        f.write(f"{new_hash}|{entry}\n")
    return new_hash
```

每次调用时传入上次返回的哈希值，事后可通过重算哈希链验证日志是否被篡改。

*延伸阅读：[LLM Agents Can Easily Tamper With Their Own Traces](https://arxiv.org/abs/2609.30266v1)*
