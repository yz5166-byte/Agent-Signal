## 今日 Agent 开发技巧

### 用 Firecrawl 一行代码搞定反爬页面抓取

当你的 Agent 需要从网页抓取结构化数据，但目标网站有反爬或动态加载时，直接用 requests 容易失败。

做法：使用 Firecrawl 的 `/scrape` API，传入 URL 并指定 `formats: ['markdown']`，它会自动处理 JS 渲染和反爬，返回干净文本。

```python
import requests

response = requests.post(
    'https://api.firecrawl.com/v1/scrape',
    json={'url': 'https://example.com', 'formats': ['markdown']},
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)
print(response.json()['data']['content'])
```

注意：API Key 不要硬编码，用环境变量 `FIRE_CRAWL_API_KEY` 读取。
