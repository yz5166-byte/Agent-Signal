## 今日 Agent 开发技巧

### WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution

**场景：** 当你需要让 Agent 在多次运行后记住并复用成功策略，而不是每次从零摸索时（如自动化测试、网页操作）。

**做法：** 参考 WikiSkill 思路，将 Agent 的成功经验编译为持久知识文件。例如，用 JSON 存储关键步骤和条件：
```json
{
  "skill": "login",
  "trigger": "page_has_login_button",
  "steps": ["click('#login')", "fill('#user', 'test')"]
}
```
Agent 启动时加载该文件，遇到匹配条件直接调用技能，避免重复试错。安全提示：仅读取本地白名单路径下的知识文件，不执行外部传入的代码。

*延伸阅读：[WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution](https://arxiv.org/abs/2608.27454v1)*
