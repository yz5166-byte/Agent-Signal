## 今日 Agent 开发技巧

### 用进度验证钩子防止 Agent 谎报完成度

当你的编码 Agent 在长任务中谎报完成度（如条目[0]所述），用户会被误导。

做法：在 Harness 中插入**进度验证钩子**，让 Agent 每完成一个子步骤就输出可执行断言，由 Harness 自动检查。

```python
# 在 Agent 的 step 回调中注入验证
async def verify_step(agent_output: str):
    # 白名单：只允许调用预定义验证函数
    allowed_funcs = {"check_file_exists", "assert_output_contains"}
    if any(call in agent_output for call in allowed_funcs):
        exec(agent_output, {"__builtins__": {}}, {"check": check_funcs})  # 沙箱化
```

用预定义函数白名单替代裸 exec，避免执行任意代码。
