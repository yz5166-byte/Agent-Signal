## 今日 Agent 开发技巧

### Pre-Crime for Agents, at the Last Second: Probing When a Recruited Agent Gives In

当多Agent协作时，某个Agent可能被恶意指令暗中攻破，传统事后审计来不及。

做法：在Agent被攻破前一刻，用探针（Probe）检测其输出是否偏离原始任务。例如在每次Agent回复前，插入一个轻量分类器判断意图是否合规：

```python
# 伪代码示意：用白名单规则做探针
def probe_agent_output(output, task_goal):
    if "忽略" in output or "绕过" in output:
        return "拦截：输出含违规意图"
    return output
```

探针只做模式匹配，不执行模型生成的代码，安全可控。

*延伸阅读：[Pre-Crime for Agents, at the Last Second: Probing When a Recruited Agent Gives In](https://arxiv.org/abs/2610.40588v1)*
