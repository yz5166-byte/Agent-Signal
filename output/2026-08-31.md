## 今日 Agent 开发技巧

### When Robots Mishear Us: Mapping the Safety Risks of Voice-Controlled Embodied AI

当你的 Agent 需要调用外部 API 或执行用户指令时，直接 `exec()` 或 `eval()` 模型生成的代码会带来严重安全风险。

**做法：** 使用 `subprocess.run()` 配合白名单命令列表，或利用 `restrictedpython` 库创建沙箱环境。

```python
import subprocess

ALLOWED_COMMANDS = {"ls", "cat", "echo"}

def safe_execute(cmd: str):
    parts = cmd.split()
    if parts[0] not in ALLOWED_COMMANDS:
        raise ValueError(f"Command {parts[0]} not allowed")
    subprocess.run(parts, check=True, capture_output=True)
```

此方案通过白名单限制可执行命令，避免裸 `exec` 风险。

*延伸阅读：[When Robots Mishear Us: Mapping the Safety Risks of Voice-Controlled Embodied AI](https://arxiv.org/abs/2608.28518v1)*
