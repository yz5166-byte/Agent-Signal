## 今日 Agent 开发技巧

### firecrawl/firecrawl

当 Agent 需要从非结构化网页或文档中提取信息时，直接喂全文会导致 token 浪费且易超上下文窗口。做法：用 `firecrawl` 的 `scrape` 接口配合 `formats: ['markdown']` 参数，自动将网页转为结构化 Markdown，再按 `#` 标题切块后分批处理。

```bash
curl -X POST https://api.firecrawl.dev/v1/scrape \
  -H 'Content-Type: application/json' \
  -d '{"url": "https://example.com", "formats": ["markdown"]}'
```

返回的 `data.markdown` 可直接按 `## ` 分割为独立段落，减少冗余 token。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
