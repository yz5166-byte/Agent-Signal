## 今日 Agent 开发技巧

### Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination

**场景**：当 Agent 需要执行网页操作（如点击、填写表单）时，常因模型幻觉导致定位错误元素。机械可解释性分析（条目[1]）发现，幻觉源于注意力机制对无关元素的误判。

**做法**：在 Agent 的 HTML 解析层加入**白名单元素过滤器**，只允许操作显式标记为 `data-agent-safe` 的节点。

```python
from bs4 import BeautifulSoup

def safe_parse(html: str) -> list:
    soup = BeautifulSoup(html, 'html.parser')
    # 仅提取白名单元素
    safe_elements = soup.select('[data-agent-safe]')
    return [el.get('data-agent-safe') for el in safe_elements]
```

**注意**：此方法不执行任何模型生成的代码，仅通过 CSS 选择器过滤 DOM，无安全风险。

*延伸阅读：[Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination](https://arxiv.org/abs/2611.18514v1)*
