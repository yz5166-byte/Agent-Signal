## 今日 Agent 开发技巧

### lexmount/moli

**场景**：当你需要让 Agent 在真实网页上执行操作（如抓取数据、填写表单），但目标网站开始封禁 AI 爬虫时。

**做法**：使用无头浏览器 `moli`（条目[7]）模拟真实用户行为。它由 Rust 编写，轻量且兼容性强，能绕过简单的反爬检测。

```rust
// 安装: cargo add moli
use moli::Browser;

#[tokio::main]
async fn main() {
    let browser = Browser::new().await.unwrap();
    let page = browser.new_page("https://example.com").await.unwrap();
    let html = page.content().await.unwrap();
    println!("{}", html);
}
```

**注意**：遵守网站 robots.txt 和当地法律，仅用于合法数据采集。
