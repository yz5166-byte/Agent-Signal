## 今日 Agent 开发技巧

### TEPA: Revoking Stale Memories for Conflict-Robust Language Agents

**场景**：Agent 在长期任务中会积累过时记忆，导致决策污染（如引用已失效的 API 文档）。

**做法**：用 TEPA 机制自动撤销过期记忆。在记忆写入时附加时间戳，查询时对比当前时间，若超过阈值（如 7 天）则标记为“待验证”，优先使用新记忆。

```python
from datetime import datetime, timedelta

MEMORY_TTL = timedelta(days=7)

def is_memory_valid(memory):
    return datetime.now() - memory['timestamp'] < MEMORY_TTL
```

安全提示：此方案仅操作本地结构化数据，不执行任意代码，无需沙箱。

*延伸阅读：[TEPA: Revoking Stale Memories for Conflict-Robust Language Agents](https://arxiv.org/abs/2608.07429v1)*
