## 今日 Agent 开发技巧

### Claude Code is accidentally exposing secrets all over GitHub

**场景**：用 Claude Code 等 AI 编程工具时，提示词可能意外泄露 API 密钥或密码（如条目 [12] 所示）。

**做法**：在调用模型前，用正则或专用库（如 `detect-secrets`）对输入做敏感信息扫描，命中则拒绝执行。

```python
import re

# 白名单：仅允许安全模式匹配，不执行任何代码
API_KEY_PATTERN = re.compile(r'(sk-[A-Za-z0-9]{32,})')

def sanitize_prompt(prompt: str) -> str:
    if API_KEY_PATTERN.search(prompt):
        raise ValueError("提示词包含疑似 API 密钥，已拦截")
    return prompt
```

将 `sanitize_prompt` 作为工具链入口，确保模型只处理脱敏后的输入。
