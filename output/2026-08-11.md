## 今日 Agent 开发技巧

### 用Ollama本地跑LLM，做Agent推理引擎

开发Agent时调用外部API有延迟与隐私风险。Ollama可一键本地运行模型，提供兼容OpenAI的API。做法：安装Ollama后运行 `ollama pull qwen2.5`，再启动服务 `ollama serve`。Agent中通过HTTP调用：
```python
import requests
resp = requests.post("http://localhost:11434/api/generate", json={"model": "qwen2.5", "prompt": "你是助手", "stream": False})
print(resp.json()["response"])
```
安全：仅调用本地服务，不执行用户代码。
