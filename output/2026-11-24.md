## 今日 Agent 开发技巧

### 用共形预测让 Text-to-SQL Agent 学会“拒绝回答”

**场景**：构建 Text-to-SQL Agent 时，模型可能生成语法正确但答案错误的 SQL，导致下游任务失败。

**做法**：用共形预测（Conformal Prediction）为每条 SQL 输出置信区间。当置信度低于阈值（如 0.8）时，让 Agent 主动拒绝执行并请求人工确认。

```python
from conformal_tool import ConformalSQL

sql_agent = ConformalSQL(model, alpha=0.2)  # 90% 置信度
sql, conf = sql_agent.predict("查询2024年销售额")
if conf < 0.8:
    print("置信度不足，请人工审核")
else:
    execute(sql)
```

**注意**：使用预训练共形预测器，无需裸执行模型输出。

*延伸阅读：[Know When to Abstain: Conformal Confidence Estimation for Text-to-SQL](https://arxiv.org/abs/2611.31190v1)*
