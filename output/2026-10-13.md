## 今日 Agent 开发技巧

### 用轻量无头浏览器替代Selenium

**场景：** 当你的Agent需要操作网页（如抓取动态内容、填写表单），但Selenium/Playwright太重或兼容性差时。

**做法：** 用Rust编写的无头浏览器 `moli`，它专为AI代理优化，支持WebSocket远程控制。安装后启动服务：
```bash
cargo install moli
moli --headless --remote-debugging-port=9222
```
然后通过HTTP API发送操作指令（如点击、截图），无需管理复杂的浏览器驱动。注意：所有远程调试端口应绑定到本地回环地址（127.0.0.1），避免外部访问。

*延伸阅读：[lexmount/moli](https://github.com/lexmount/moli)*
