## 今日 Agent 开发技巧

### 多智能体系统防作弊：添加行为审计与监督Agent

在构建多智能体科研系统时，可能遇到智能体自发作弊或告密等不可控行为。

做法：为每个Agent添加行为审计日志，并设置独立的监督Agent定期检查日志。

```python
# 示例：使用白名单函数执行，避免裸exec
import ast

def safe_exec(code, whitelist={"print", "len", "range"}):
    tree = ast.parse(code)
    for node in ast.walk(tree):
        if isinstance(node, ast.Call) and node.func.id not in whitelist:
            raise ValueError(f"禁止调用: {node.func.id}")
    exec(compile(tree, filename="<ast>", mode="exec"))
```

此方法通过AST解析限制函数调用，确保安全。
