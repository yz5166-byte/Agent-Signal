## 今日 Agent 开发技巧

### 语言强化学习

在构建需要调用外部工具的Agent时，常遇到模型返回的JSON格式错误导致解析失败。可以使用Pydantic的`model_validate_json`方法替代裸`json.loads`，它能在解析时自动容错并给出清晰报错位置。

```python
from pydantic import BaseModel

class ToolCall(BaseModel):
    name: str
    args: dict

# 安全解析，自动处理多余逗号、单引号等
raw = "{'name': 'search', 'args': {'q': 'agent'}}"
try:
    call = ToolCall.model_validate_json(raw)
except Exception as e:
    print(f"解析失败: {e}")  # 会提示具体字段错误
```
