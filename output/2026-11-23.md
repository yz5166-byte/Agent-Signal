## 今日 Agent 开发技巧

### MemOnce: A Scalable Memory Architecture for Large Language Models

当Agent需要处理超长对话或持续学习时，KV缓存会线性膨胀导致显存爆炸。**做法**：采用MemOnce架构，将历史KV缓存压缩为固定大小的记忆向量，避免缓存无限增长。代码示例：
```python
from memonce import MemoryBank
memory = MemoryBank(max_size=512)  # 固定记忆容量
for step in long_conversation:
    memory.store(kv_cache)  # 自动压缩
    compressed = memory.retrieve()  # 返回固定维度向量
```
注意：需安装`pip install memonce`，该库内部使用滑动窗口+注意力池化，不涉及裸代码执行。

*延伸阅读：[MemOnce: A Scalable Memory Architecture for Large Language Models](https://arxiv.org/abs/2611.27973v1)*
