## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的Agent需要从网页抓取结构化数据（如新闻列表、商品价格）时，直接用requests+BeautifulSoup常因反爬或动态渲染失败。

**做法**：用`firecrawl`的API一键爬取并返回Markdown。
```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
# 爬取并自动处理JS渲染、反爬
result = app.scrape_url("https://example.com", params={"formats": ["markdown"]})
print(result["markdown"][:500])  # 直接取干净文本
```
注意：API密钥需从[firecrawl.dev](https://firecrawl.dev)获取，免费额度足够日常调试。
