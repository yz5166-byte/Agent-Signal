## 今日 Agent 开发技巧

### Kaer: Security-Aware Replanning for Multi-Agent Systems

**场景**：你在构建多智能体系统时，发现动态重规划（replanning）存在安全漏洞——比如某个Agent被劫持后，会诱导其他Agent执行危险操作。

**做法**：使用Kaer框架的安全感知重规划机制，在每次重规划前插入一个**安全验证层**。代码示例：
```python
# 白名单验证器，只允许预定义的action
SAFE_ACTIONS = {"read", "write", "query"}
def safe_replan(proposed_action):
    if proposed_action not in SAFE_ACTIONS:
        raise SecurityError(f"Blocked: {proposed_action}")
    return proposed_action
```
将`safe_replan`作为重规划流程的守卫函数，拒绝任何未授权的操作。

*延伸阅读：[Kaer: Security-Aware Replanning for Multi-Agent Systems](https://arxiv.org/abs/2611.24839v1)*
