## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的 Agent 需要从网页抓取动态内容（如实时股价、商品价格），但传统爬虫拿不到渲染后的数据时，可以用 FireCrawl 的 API 直接获取。做法：安装 `firecrawl-py`，调用 `crawl_url` 并指定 `pageOptions` 为 `{onlyMainContent: true}` 过滤噪声。代码示例：

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
result = app.crawl_url(
    url="https://example.com",
    params={"pageOptions": {"onlyMainContent": True}}
)
print(result["data"][0]["content"])
```

注意：API Key 通过环境变量传入，不要硬编码。若需执行返回的代码，用 `subprocess.run` 配合白名单路径。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
