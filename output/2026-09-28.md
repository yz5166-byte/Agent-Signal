### 根据任务结构限制多智能体规模

**场景：** 多智能体协作时，任务结构不同，增加智能体数量效果天差地别——补偿型任务（如投票）人多好，析取型任务（如找唯一解）人多反而乱。

**做法：** 部署前先用小规模实验判断任务类型。对析取型任务，限制参与智能体数量（如≤3），并引入“仲裁者”智能体做最终决策。

```python
# 示例：限制析取型任务的智能体数量
MAX_AGENTS = 3
agents = get_available_agents()
if task_type == "disjunctive":
    selected_agents = agents[:MAX_AGENTS]
    result = arbiter.decide([a.run(task) for a in selected_agents])
```
