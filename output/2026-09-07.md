## 今日 Agent 开发技巧

### langchain-ai/openwiki

**场景**：当Agent需要调用多个外部API（如政府数据、天气、健康等）完成复杂任务时，手动编排工具调用顺序容易出错且效率低。

**做法**：使用 `langchain-ai/openwiki` 的CLI工具，自动为代码库生成工具调用文档，确保Agent能实时理解API的输入输出格式。

```bash
# 安装并运行openwiki，自动扫描代码库中的工具定义
pip install openwiki
openwiki generate --path ./tools --output docs/agent_tools.md
```

**安全提示**：openwiki仅读取代码文件生成文档，不执行任何代码，无安全风险。

*延伸阅读：[langchain-ai/openwiki](https://github.com/langchain-ai/openwiki)*
