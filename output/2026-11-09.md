## 今日 Agent 开发技巧

### Compaction, decay and reinforcement in a two-tier conversational memory: a paired evaluation against retrieval-augmented generation

**场景**：Agent 需要长期记忆对话历史，但 RAG 检索会丢失上下文连贯性，导致回答碎片化。

**做法**：改用双层压缩记忆策略。第一层用 LLM 对每轮对话生成摘要并压缩存储；第二层在检索时只返回压缩后的关键摘要，而非原始对话。

```python
# 伪代码示例：使用 LangChain 的 ConversationSummaryMemory
from langchain.memory import ConversationSummaryMemory
from langchain.llms import OpenAI

memory = ConversationSummaryMemory(
    llm=OpenAI(),
    max_token_limit=500  # 控制压缩后摘要长度
)
memory.save_context({"input": "用户问题"}, {"output": "Agent回答"})
print(memory.load_memory_variables({}))  # 返回压缩后的摘要
```

**注意**：压缩过程需在沙箱环境（如 Docker 容器）中运行 LLM，避免直接暴露 API Key。

*延伸阅读：[Compaction, decay and reinforcement in a two-tier conversational memory: a paired evaluation against retrieval-augmented generation](https://arxiv.org/abs/2611.09807v1)*
