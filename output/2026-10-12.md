## 今日 Agent 开发技巧

### RATED: Reliability-Aware AI Agent Tool Retrieval via Execution Dynamics

**场景：** 当你的 Agent 需要调用外部工具（如搜索、API），但工具可能临时不可用或响应超时，导致整个任务失败。

**做法：** 采用“可靠性感知”策略——在调用前先对工具进行轻量级健康检查（ping/心跳），并维护一个可用性缓存。

```python
import asyncio

async def safe_tool_call(tool_name, tool_func, health_check):
    if not await health_check(tool_name):  # 例如：检查HTTP 200
        return {"error": f"{tool_name} 不可用"}
    return await tool_func()
```

若工具返回错误，自动降级到备选工具或返回缓存结果，避免 Agent 卡死。
