## 今日 Agent 开发技巧

### 用代码替代JSON调用工具

当你的Agent需要调用外部工具时，别再用JSON定义参数——改用直接执行代码的方式。

场景：LLM调用工具时，JSON结构容易出错且限制灵活性，尤其在动态参数或嵌套逻辑场景下。

做法：让Agent生成并执行Python代码来调用工具，而非解析JSON。例如用`exec()`或`eval()`安全执行代码片段：
```python
# 传统JSON方式（易出错）
# tool_call = {"name": "search", "args": {"query": "AI"}}

# 代码方式（更灵活）
code = "result = search('AI')"
exec(code, globals())
print(result)
```
注意限制执行环境权限，避免安全风险。

*延伸阅读：[The Bitter Lesson of Tool Calling](https://arxiv.org/abs/2608.06370v1)*
