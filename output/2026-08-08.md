## 今日 Agent 开发技巧

### The Bitter Lesson of Tool Calling

当你的Agent需要并行调用多个工具（如同时查询天气和日历），但系统将工具调用视为JSON导致顺序阻塞时，可以改用代码式工具调用范式。做法：将工具签名定义为函数，让模型生成并行函数调用代码。

```python
import asyncio

async def call_tools():
    tasks = [
        get_weather("北京"),
        get_calendar_events("2024-03-20")
    ]
    return await asyncio.gather(*tasks)
```

注意：在沙箱环境（如Docker容器）中执行模型生成的代码，并限制文件系统与网络权限。

*延伸阅读：[The Bitter Lesson of Tool Calling](https://arxiv.org/abs/2608.06370v1)*
