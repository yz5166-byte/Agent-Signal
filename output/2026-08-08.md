## 今日 Agent 开发技巧

### 用脚本替代JSON工具调用

当Agent需要频繁调用多个工具（如搜索、计算）时，JSON序列化和HTTP请求会成为性能瓶颈。可以将工具实现为Python函数，用`ProcessPoolExecutor`并行执行，避免解析开销。注意：工具函数必须来自白名单，不执行用户提供的任意代码。

```python
from concurrent.futures import ProcessPoolExecutor

def safe_calc(expr):
    # 仅允许安全运算（示例用eval，实际应替换为ast.literal_eval或受限计算）
    return eval(expr, {"__builtins__": {}}, {"x": 1})

tools = {"search": lambda q: f"result_{q}", "calc": safe_calc}

with ProcessPoolExecutor() as pool:
    futures = {pool.submit(func, arg): name for name, func in tools.items()}
```

*延伸阅读：[The Bitter Lesson of Tool Calling](https://arxiv.org/abs/2608.06370v1)*
