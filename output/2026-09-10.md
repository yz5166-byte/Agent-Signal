## 今日 Agent 开发技巧

### Avatar: Toward Autonomous End-to-End Orchestration of Scientific Workflows using LLMs

**场景**：当你需要让 Agent 在本地安全地执行用户或模型生成的 Python 代码（如科学计算、数据处理）时，直接使用 `exec` 或 `eval` 存在严重安全风险。

**做法**：使用 `subprocess` 在隔离的子进程中运行代码，并设置超时和资源限制。示例：

```python
import subprocess

def run_code_safely(code: str, timeout: 10):
    try:
        result = subprocess.run(
            ['python3', '-c', code],
            capture_output=True, text=True, timeout=timeout
        )
        return result.stdout
    except subprocess.TimeoutExpired:
        return "Timeout"
```

此方法将代码交给独立 Python 进程执行，即使崩溃也不会影响主 Agent 进程。
