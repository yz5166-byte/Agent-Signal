## 今日 Agent 开发技巧

### 用 firecrawl 一键抓取网页结构化数据

当你的 Agent 需要从网页抓取结构化数据，但目标网站频繁改版或反爬时，可用 `firecrawl` 的 API 一键提取。做法：安装 `firecrawl` 包，调用 `crawl_url` 方法，指定目标 URL 和输出格式（如 Markdown）。代码示例：
```python
from firecrawl import Firecrawl
fc = Firecrawl(api_key='your_key')
result = fc.crawl_url('https://example.com', output_format='markdown')
print(result['content'])
```
注意：API 密钥需从 firecrawl.dev 获取，不要硬编码在公开仓库中。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
