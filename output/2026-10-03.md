### AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents

在构建需要长期运行的编码Agent时，上下文窗口会不断膨胀，导致推理变慢、成本飙升。

**做法**：参考AutoCompact的思路，在Agent的循环中插入一个压缩决策点。当历史token数超过阈值（如8K）时，调用LLM判断是否压缩，并用摘要替换旧对话。

```python
import tiktoken

def maybe_compact(history: list, model="gpt-4"):
    enc = tiktoken.encoding_for_model(model)
    if len(enc.encode(str(history))) > 8000:
        # 调用LLM生成摘要，替换前80%的历史
        summary = llm_summarize(history[:int(len(history)*0.8)])
        return [summary] + history[int(len(history)*0.8):]
    return history
```

注意：压缩函数需在沙箱（如Docker容器）中调用，避免LLM输出注入主进程。

*延伸阅读：[AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents](https://arxiv.org/abs/2610.02163v1)*
