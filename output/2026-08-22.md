## 今日 Agent 开发技巧

### firecrawl/firecrawl

**场景：** 用 `firecrawl` 抓取网页内容时，直接返回原始 HTML 或 Markdown 可能混入广告、导航栏等噪声，影响下游 RAG 或 LLM 解析质量。

**做法：** 使用 `firecrawl` 的 `scrape` API 并指定 `formats: ["markdown"]` 和 `onlyMainContent: true`，自动过滤非正文元素。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your-key")
result = app.scrape_url(
    "https://example.com/article",
    params={"formats": ["markdown"], "onlyMainContent": True}
)
clean_text = result["markdown"]
```

**注意：** 该参数由服务端处理，本地无需执行任何模型生成的代码，安全无风险。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
