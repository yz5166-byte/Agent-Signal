## 今日 Agent 开发技巧

### 跨会话上下文状态持久化

当Agent需要跨会话处理长任务（如多轮数据采集）时，上下文学习状态会丢失。做法：用外部存储序列化当前会话的上下文示例（in-context examples）和中间推理链，在下一会话开始时注入。

```python
import json
# 保存状态
state = {"examples": [...], "chain": [...]}
with open("agent_state.json", "w") as f:
    json.dump(state, f)
# 恢复状态
with open("agent_state.json") as f:
    state = json.load(f)
```

注意：仅存储纯文本/JSON，不执行任何代码，安全无风险。
