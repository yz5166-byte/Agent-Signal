## 今日 Agent 开发技巧

### Quantifying Claim Smoothing by LLM Research Agents

**场景**：Agent 在长文档综合时，容易生成“平滑但虚假自信”的结论（条目[1]），误导研究决策。

**做法**：在 Agent 输出结论前，强制要求它引用原文中的具体段落编号，并标注置信度（高/中/低）。若置信度为“高”，必须附带至少两条直接支持该结论的原文引用。

```python
# 示例：在生成最终结论前调用此函数
def validate_claim(claim, sources):
    if claim.confidence == "高":
        assert len(sources) >= 2, "高置信度结论需至少2条原文引用"
    return True
```
