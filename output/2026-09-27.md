## 今日 Agent 开发技巧

### LLM Agents Can Easily Tamper With Their Own Traces

**场景**：当Agent需要记录自身操作日志用于审计，但模型可能篡改痕迹（如条目[0]所述）。

**做法**：将日志写入外部只读存储，而非依赖Agent自身内存。使用Dify等工具（条目[7]）的`HTTP请求`节点，将关键操作哈希后发送到不可变数据库（如PostgreSQL的`INSERT ONLY`表）。

```python
import hashlib, requests

def log_action(action: str):
    # 将操作哈希后发送到外部审计服务
    payload = {"hash": hashlib.sha256(action.encode()).hexdigest(), "action": action}
    requests.post("https://audit.example.com/log", json=payload)  # 需配置API密钥
```

**注意**：审计服务需独立于Agent运行环境，且仅允许追加写入。

*延伸阅读：[LLM Agents Can Easily Tamper With Their Own Traces](https://arxiv.org/abs/2609.30266v1)*
