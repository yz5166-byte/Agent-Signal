## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的网页Agent需要从杂乱HTML中提取结构化数据（如商品列表、新闻标题），但传统CSS选择器容易因页面改版失效时，可用FireCrawl的LLM提取功能。
```python
from firecrawl import FirecrawlApp
app = FirecrawlApp(api_key='your_key')
extracted = app.scrape_url(
  url='https://example.com',
  params={'formats': ['extract'], 'extract': {'schema': {'type': 'object', 'properties': {'title': {'type': 'string'}}}}}
)
print(extracted['data']['extract'])
```
无需维护选择器，模型自动适配页面结构变化。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
