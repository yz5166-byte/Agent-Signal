## 今日 Agent 开发技巧

### Actions Speak Louder than Words: Measuring Cross-Lingual Policy Retention in Tool-Using Agents

当你的Agent需要执行用户提供的代码（如数学公式、SQL查询）时，直接使用`exec`或`eval`会带来严重安全风险。

**做法**：用`subprocess`在隔离的Docker容器中运行代码，并设置资源限制。

```python
import subprocess
import docker

def safe_exec(code: str):
    client = docker.from_env()
    container = client.containers.run(
        "python:3.11-slim",
        command=["python", "-c", code],
        mem_limit="256m",
        cpu_period=100000, cpu_quota=50000,
        remove=True,
        stdout=True, stderr=True
    )
    return container.decode()
```

此方案基于条目[0]中跨语言工具调用安全性的警示，防止恶意代码通过Agent执行。

*延伸阅读：[Actions Speak Louder than Words: Measuring Cross-Lingual Policy Retention in Tool-Using Agents](https://arxiv.org/abs/2608.11110v1)*
