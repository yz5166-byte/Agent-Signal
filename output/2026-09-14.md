## 今日 Agent 开发技巧

### 用 firecrawl 的 `onlyMainContent` 参数一键清洗网页正文

**场景：** 用 `firecrawl` 为 RAG 或 Agent 抓取网页时，直接返回的 HTML 或 Markdown 可能混入广告、导航栏等无关内容，导致检索质量下降。

**做法：** 使用 `firecrawl` 的 `scrape` 接口并指定 `formats: ["markdown"]` 和 `onlyMainContent: true`，自动过滤非正文元素。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your-key")
result = app.scrape_url(
    "https://example.com/article",
    params={"formats": ["markdown"], "onlyMainContent": True}
)
clean_text = result["markdown"]
```

**注意：** 若需执行抓取结果中的代码，应先用 `html.unescape()` 转义，再在 Docker 沙箱内运行。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
