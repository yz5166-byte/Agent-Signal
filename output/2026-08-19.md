## 今日 Agent 开发技巧

### firecrawl/firecrawl

当你的 Agent 需要从网页抓取结构化数据（如新闻标题、商品价格），而目标网站有反爬或动态加载时，直接用 requests 会失败。

做法：用 firecrawl 的 `scrapeUrl` API 替代。它内置浏览器渲染，返回干净 Markdown。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your-key")
result = app.scrape_url("https://example.com", params={"formats": ["markdown"]})
print(result["markdown"][:500])  # 取前500字符
```

注意：API Key 需从环境变量读取，不要硬编码。若需执行模型生成的抓取代码，用 `subprocess.run` 在 Docker 容器内运行，避免直接调用系统命令。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
