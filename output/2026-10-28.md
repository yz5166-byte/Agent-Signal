## 今日 Agent 开发技巧

### genspark-ai/genoffice

当你的Agent需要生成真实Office文档（如报告、合同）时，直接调用API返回的Markdown往往格式错乱。

做法：使用 [genoffice](https://github.com/genspark-ai/genoffice) 库，让Agent通过Python操作本地Office文件。

```python
from genoffice import Document

doc = Document()
doc.add_heading('周报', level=1)
doc.add_paragraph('本周完成三项任务...')
doc.save('report.docx')  # 直接生成可打开的.docx文件
```

注意：genoffice在本地沙箱中运行，不执行模型生成的代码，仅调用预定义API，安全无风险。

*延伸阅读：[genspark-ai/genoffice](https://github.com/genspark-ai/genoffice)*
