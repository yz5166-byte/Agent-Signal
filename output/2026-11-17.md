## 今日 Agent 开发技巧

### MCP 工具名劫持防御

当你的 Agent 调用 MCP 工具时，工具名可能被恶意服务器劫持（条目[0]）。做法：在调用前对工具来源做白名单校验，只允许信任的 server 注册工具名。

```python
# 白名单：只允许来自 trusted_servers 的工具
TRUSTED_SERVERS = {"server-a", "server-b"}

def safe_call_tool(tool_name, server_id):
    if server_id not in TRUSTED_SERVERS:
        raise PermissionError(f"Untrusted server: {server_id}")
    # 继续调用工具...
```

不要依赖工具名作为唯一身份标识，始终绑定 server 来源。

（沙箱提示：若需执行模型生成的代码，用 Docker 容器或 subprocess 限制文件/网络权限，禁止裸 exec/eval。）

*延伸阅读：[When Tool Names Are Not Identities: Measuring Provider Misbinding in MCP-Based AI Agents](https://arxiv.org/abs/2611.21577v1)*
