## 今日 Agent 开发技巧

### 用代码调用替代JSON调用

当Agent需要链式或并行调用多个工具时，JSON格式的解析与序列化会成为性能瓶颈。将每个工具封装为Python函数，通过直接函数调用代替JSON-Calling，可显著提升效率。做法：定义工具函数后，Agent直接调用函数并处理返回值，无需中间JSON转换。例如：
```python
def search_web(query: str) -> str:
    return "结果"
def calculate(expr: str) -> float:
    return eval(expr)
# Agent直接调用
result = search_web("天气") + str(calculate("2+2"))
```

*延伸阅读：[The Bitter Lesson of Tool Calling](https://arxiv.org/abs/2608.06370v1)*
