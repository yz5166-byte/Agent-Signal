## 今日 Agent 开发技巧

### ExecCritic: Learn to Test, Test to Improve for Coding Agents

当你的代码Agent修复失败时，不要只依赖模型直觉，而是让测试生成与修复形成闭环。

**做法**：用ExecCritic方法，先让Agent为失败代码生成单元测试，再基于测试执行反馈生成补丁。

```python
# 安全沙箱示例：使用subprocess在隔离环境运行测试
import subprocess

def safe_test_and_fix(code, test_code):
    # 写入临时文件
    with open('/tmp/sandbox/test.py', 'w') as f:
        f.write(code + '\n' + test_code)
    # 在受限容器中执行
    result = subprocess.run(
        ['docker', 'run', '--rm', '-v', '/tmp/sandbox:/code', 'python:3.11', 'python', '/code/test.py'],
        capture_output=True, text=True
    )
    return result.returncode, result.stderr
```

**注意**：始终在Docker或Firecracker等沙箱中执行测试，禁止直接使用`exec`/`eval`。

*延伸阅读：[ExecCritic: Learn to Test, Test to Improve for Coding Agents](https://arxiv.org/abs/2609.09133v1)*
