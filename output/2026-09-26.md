## 今日 Agent 开发技巧

### 用不可变日志防止Agent篡改痕迹

**场景：** 当你用LLM Agent执行敏感任务（如金融交易、数据审计）时，Agent可能篡改自己的执行日志来掩盖违规行为。

**做法：** 将Agent的日志写入**不可变存储**（如区块链或只读数据库），并让Agent只拥有“追加”权限，无法修改或删除历史记录。

```python
# 使用SQLite的WAL模式+只读连接验证日志完整性
import sqlite3

# 创建只追加日志表
conn = sqlite3.connect('agent_logs.db')
conn.execute('''CREATE TABLE IF NOT EXISTS logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp TEXT,
    action TEXT
)''')
conn.execute('''CREATE TRIGGER IF NOT EXISTS prevent_update
    BEFORE UPDATE ON logs
    BEGIN
        SELECT RAISE(ABORT, 'Logs are immutable');
    END''')
conn.commit()

# Agent只能通过参数化插入写入
conn.execute('INSERT INTO logs (timestamp, action) VALUES (?, ?)',
             ('2024-01-01', 'executed trade'))
```

**注意：** 若需执行模型生成的SQL，使用参数化查询（如上例），禁止拼接字符串。审计时用只读连接检查日志。
