## 今日 Agent 开发技巧

### firecrawl/firecrawl

**场景：** 当你的 Agent 需要从网页抓取结构化数据（如商品列表、新闻标题），但目标网站没有 API 时，手动写解析规则既脆弱又费时。

**做法：** 用 `firecrawl` 库一键将网页转为 Markdown 或结构化 JSON，再交给 LLM 处理。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
result = app.scrape_url("https://example.com", params={"formats": ["markdown"]})
print(result["markdown"])  # 直接获得干净文本
```

**注意：** 无需 `exec/eval`，Firecrawl 在云端沙箱执行抓取，返回安全数据。安装：`pip install firecrawl-py`。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
