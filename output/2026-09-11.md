## 今日 Agent 开发技巧

### 用动态驱力替代静态目标，解决Agent长期行为漂移

在构建长期自主Agent时，静态目标会导致行为漂移。若想让Agent在数小时任务中保持行为一致性，可引入“驱力”概念：用动态优先级队列替代固定目标。

做法：在Agent循环中维护一个优先级列表，每次决策前根据当前状态重新排序。
```python
# 安全写法：仅操作内部数据结构，不执行外部代码
drives = [
    {"name": "explore", "priority": 0.8},
    {"name": "exploit", "priority": 0.5}
]
# 根据环境反馈更新优先级
def update_drives(state):
    for d in drives:
        d["priority"] *= (1 + 0.1 * state.get(d["name"], 0))
    drives.sort(key=lambda x: x["priority"], reverse=True)
    return drives[0]["name"]
```
此方法无需执行模型生成代码，仅调整Agent内部逻辑。
