## 今日 Agent 开发技巧

### firecrawl/firecrawl

**场景：** 当你的 Agent 需要从海量网页中提取结构化数据（如竞品价格、新闻列表），但目标网站没有 API 时，手动写爬虫既慢又易被屏蔽。

**做法：** 用 `firecrawl` 的 `crawl` 命令一键抓取并转为 Markdown。先安装 `pip install firecrawl-py`，再运行：

```python
from firecrawl import FirecrawlApp
app = FirecrawlApp(api_key="your-key")
result = app.crawl(url="https://example.com", params={"limit": 50, "scrapeOptions": {"formats": ["markdown"]}})
# result 包含所有页面的 Markdown 内容，可直接喂给 LLM 解析
```

注意：`api_key` 需从 [firecrawl.dev](https://firecrawl.dev) 获取，免费额度足够日常测试。代码只调用官方 SDK，不执行任何用户输入，安全无风险。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
