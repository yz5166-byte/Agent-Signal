## 今日 Agent 开发技巧

### Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)

当你的Agent需要执行模型生成的代码（如自动修复漏洞或操作数据库）时，直接使用`exec`/`eval`存在安全风险。

做法：用`subprocess`在沙箱中运行，并设置白名单命令。

```python
import subprocess

def safe_exec(code: str, allowed_commands: set):
    # 仅允许白名单内的命令
    if any(cmd in code for cmd in allowed_commands):
        result = subprocess.run(
            ['python3', '-c', code],
            capture_output=True, text=True, timeout=5
        )
        return result.stdout
    else:
        raise PermissionError("Command not allowed")

# 示例：只允许 'print' 和 'list'
allowed = {'print', 'list'}
print(safe_exec("print('hello')", allowed))
```

此方法隔离了系统调用，避免恶意代码影响宿主环境。

*延伸阅读：[Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)](https://arxiv.org/abs/2611.26553v1)*
