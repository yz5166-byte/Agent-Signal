### Does an Agent's History Tell You When Compaction Will Hurt? A Modest, Bounded Effect on the TRACE Paired-Replay Corpus

当你的Agent需要长期运行且上下文窗口有限时，会遇到历史记录过长导致性能下降或成本飙升的问题。做法：使用基于**交互轮次**的滑动窗口压缩，保留最近N轮完整对话，将更早的历史用摘要替换。

```python
from collections import deque

class SlidingWindowMemory:
    def __init__(self, max_rounds=10):
        self.history = deque(maxlen=max_rounds)
        self.summary = ""

    def add(self, user_msg, agent_action):
        if len(self.history) == self.history.maxlen:
            self.summary += f"[摘要] {self.history[0]['user']} -> {self.history[0]['action']}\n"
        self.history.append({"user": user_msg, "action": agent_action})

    def get_context(self):
        return self.summary + "\n".join(
            f"用户: {h['user']}\nAgent: {h['action']}" for h in self.history
        )
```

（基于条目[4]的实证结论：适度压缩对性能影响有限）
