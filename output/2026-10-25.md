## 今日 Agent 开发技巧

### firecrawl/firecrawl

**场景**：当你的Agent需要实时抓取网页数据喂给大模型，但传统爬虫无法处理JS渲染或反爬时。

**做法**：用 `firecrawl` 替代requests，一行代码让Agent拿到干净Markdown。

```python
from firecrawl import FirecrawlApp

app = FirecrawlApp(api_key="your_key")
content = app.scrape_url("https://example.com", formats=["markdown"])
# 直接返回纯文本，无需处理HTML或JS
```

**注意**：`firecrawl` 自带渲染和反爬，无需自己写沙箱。若需执行模型生成的抓取代码，用白名单限制域名（如 `allowed_domains=["example.com"]`）。

*延伸阅读：[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)*
